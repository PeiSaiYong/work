2

WhatsApp previews

Base44 can't make a per-card WhatsApp preview as is (scope section 10). The options:

OptionWhat you getCost
A. One Minmed previewEvery shared link shows the same preview: Minmed logo and “Minmed digital name card”. Everything stays on Base44.Simplest. Drops the spec's per-card preview.
B. Card served by a backend functionPer-card preview on Base44, but links look like me.minmed.sg/functions/card?code=….Untested. Uglier links.
C. Public card pages on a small separate hostPer-card previews, clean links, and full control of noindex, contact files and the visitor's IP address. The admin console stays on Base44.An extra service, its cost, and more build work.

Plan Confirmed: test option B on a throwaway app first, which takes a day or two. If it doesn't work cleanly, choose C if per-card previews are a must, otherwise A (open item 1).

3

Test before the build

On a throwaway app on a test subdomain, before the build starts.

  1. Open a card link as WhatsApp and as Google's crawler. Check the preview tags, the noindex instruction and the sitemap, then share the link in a real WhatsApp chat.
  2. Show Turnstile on the card page, verify its token in a backend function, and log the request headers to find the visitor's IP address. Then try rule 1 and the 30-minute pass from one phone, and from two phones on the same Wi-Fi.
  3. Download a contact file and open the Google Wallet link from a backend function in iPhone Safari, Android Chrome, WhatsApp and Gmail. Add the pass, edit the card and check the pass updates, then deactivate the card and check the pass shows as expired.
  4. Add a card's QR code to Apple Wallet with Create a Pass on two iPhones: one with Apple Intelligence and one without.
  5. Check that a non-minmed Google account is refused, an Admin can't make themselves Super admin, a staff member can't open another card or the admin console, and an anonymous visitor can't list cards.
  6. Sign in to My card as a staff member on a phone. Check they can change only the alias, that Preview changes nothing until they save, that the old link then shows “No card found”, and that the Google Wallet pass updates and a new card email arrives.
  7. Check that emails reach staff and manage@minmed.sg.
