The link you shared

Zapkad's example card was at zapkad.com/biz-card/DrLeeJerEn/DrLe-Ru1770: a name, then a short random code. Minmed's links leave out the name and use only a long random code: me.minmed.sg/card/qB8Rh9sTxKuaSF3YkGmD2w.

Two things Minmed does differently

  • Zapkad's card pages don't tell Google “don't index”. It relies on never listing cards anywhere, so a card link posted on a public website can still be picked up. Minmed does both: no list of cards and a noindex instruction on every card page and file.
  • Zapkad's Save to Phone link uses a disguised counting number. The example card's contact file is at /save-contact/MTY5OTM5, which decodes to 169939, not the random code. That pattern could let someone download other people's contact files by counting. It wasn't tested. Minmed's contact files use the random code.
